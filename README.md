# DesignCritic AI

AI-powered design critique that analyzes your designs, scores them, gives honest feedback, and even roasts your design.

## Features

- AI-powered design analysis
- Visual quality scoring
- Context-aware feedback
- Roast Mode
- Compare designs
- Analysis history

## Tech Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- AI: Google Gemini

## Setup

### Frontend

```bash
cd designcritic-ai
npm install
npm run dev
```
### Backend

```bash
cd backend
npm install
npm run dev
```

Create a .env file inside backend:
